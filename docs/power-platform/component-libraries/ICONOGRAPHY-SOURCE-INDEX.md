## Power Apps implementation rule

Do not mark a Fluent icon as NTT/Basecoat brand-final solely because it is semantically similar. Verify the Basecoat source glyph first, then reproduce that verified appearance in Power Apps with accessible and theme-aware behavior.

No exact selector, class name, Unicode value or pseudo-element mapping is documented here because the live Basecoat resources could not be retrieved by the current web tool on 2026-08-28.
