## Naming note

- `UI-###` names preserve evidence identifiers that are already known from the project documentation or were explicitly established in the conversation.
- `SNAP-###` names are snapshots whose exact durable UI identifier could not be established safely from the currently available documentation. They are included rather than being assigned a false UI number.
- UI-025 uses letter suffixes because the NTT DATA visual-reference baseline is a multi-image evidence set.
