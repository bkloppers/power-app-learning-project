# Dataverse — Step-by-Step Guide

Status: ACTIVE
Baseline: August 2026

## Scope

Dataverse tables, columns, relationships, choices, security, business rules, auditing and Dataverse capabilities if/when used by this project.

## Documentation rule

For every Dataverse action record the exact maker/admin path, table/column/relationship names, schema names, data types, required settings, security implications, screenshot evidence, validation result and next step.

Do not introduce Dataverse into the implementation unless the approved project design requires it; this guide exists so any future Dataverse work is documented separately and completely.
