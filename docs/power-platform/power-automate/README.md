# Power Automate — Step-by-Step Guide

Status: ACTIVE
Baseline: August 2026

## Scope

Cloud flows, triggers, actions, connection references, retries, error handling, notifications, approvals and service-side automation used by this project.

## Documentation rule

For every flow or flow change record:
- solution and flow name;
- trigger;
- connections/connection references;
- each action in order;
- expressions and dynamic content used;
- conditions/loops/scopes;
- retry/error behavior;
- exact Maker UI path;
- snapshot evidence;
- test inputs;
- observed result;
- corrections and next step.

No flow instruction is considered current until it is checked against August 2026-or-later Microsoft guidance and, when available, the observed tenant UI.
