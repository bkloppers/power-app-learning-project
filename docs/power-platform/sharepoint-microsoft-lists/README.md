# SharePoint and Microsoft Lists — Step-by-Step Guide

Status: ACTIVE
Baseline: August 2026

## Scope

SharePoint sites, Microsoft Lists, columns, views, permissions, indexing, delegation-related setup and Power Apps integration used by Tool 01.

## Current project direction

Microsoft Lists / SharePoint Lists is the approved initial Tool 01 data platform. The detailed lists have not yet been created.

## Documentation rule

For every list/data-source action record:
- site/list name;
- exact creation/configuration path;
- column display and internal names where known;
- column type and settings;
- indexes/views;
- permissions/security implications;
- Power Apps connector/data-source name;
- delegation considerations;
- snapshot evidence;
- validation result;
- next step.
